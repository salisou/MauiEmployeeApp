📌 Overview
Employee Manager App è un’applicazione sviluppata con .NET MAUI che permette di gestire facilmente un elenco di dipendenti tramite un’interfaccia moderna e intuitiva.

L’app supporta:
- Inserimento dipendenti
- Modifica dipendenti
- Eliminazione dipendenti
- Ricerca in tempo reale
- UI moderna in stile Material/iOS
- Database locale SQLite

È progettata per essere semplice, veloce e cross‑platform (Android, iOS, Windows, macOS).

- ✨ Funzionalità
- 🔍 Ricerca dinamica mentre digiti
- ➕ Aggiunta di nuovi dipendenti
- ✏️ Modifica con doppio tap
- ❌ Eliminazione con conferma
- 💾 Persistenza dati con SQLite
- 🎨 UI moderna con Border, Shadow e gradienti

🔄 Refresh automatico dopo insert/update/delete

🛠️ Tecnologie utilizzate
- .NET MAUI
- C# 
- SQLite + SQLite-net
- MVVM-ready architecture
- XAML UI con Border, Shadow, GradientBrush
